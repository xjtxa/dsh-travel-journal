# 旅行记忆 · DSH 桌面插件

一次放入混合日期、地点的照片，写一句说明。插件保存原图，读取各自拍摄时间后自动按天归档，同一天内再按城市分组，用 DSH 的模型生成每张照片的描述、标签及当天摘要。搜索先按城市和年份筛选，再用描述和标签查找相关照片。

这是独立外挂插件：使用 DSH 现有侧栏、主面板、模型和附件接口，不修改 DSH 本体、Aurabot 或其他 DSH 项目的源码。当前版本以桌面本地导入为入口，QQ 接入暂不启用。

## 安装

需要已初始化的 DeepSeek Harness 桌面版，版本为 `>=0.2.1-rc.5 <0.3.0`。在 Windows PowerShell 中运行以下命令前，先完全退出 DSH。

```powershell
& "$env:LOCALAPPDATA\Programs\DeepSeek Harness\resources\runtime\cli\bin\dsh.cmd" plugin --profile desktop add github:xjtxa/dsh-travel-journal#v0.2.5
```

也可在 DSH 的「安装第三方插件」中填写 `github:xjtxa/dsh-travel-journal#v0.2.5`。DSH 会从 GitHub 下载插件，从 npm 下载运行依赖并管理插件，完成后重新启动 DSH。本仓库直接提供可运行的 JavaScript 和客户端文件，安装时无需构建。

国内网络可在安装界面选择 npmmirror，或在上面的命令末尾添加 `--registry=https://registry.npmmirror.com`，用于下载运行依赖。插件仓库本身仍需要能连接 GitHub。发布页提供 Windows x64 ZIP 离线包，可下载后传给其他电脑安装。

ZIP 离线包需完整解压，退出 DSH 后双击「双击安装.cmd」。安装器校验文件并复制到 DSH 用户目录中的固定位置，使用 DSH 自带运行时完成注册；成功后可删除下载的 ZIP 和解压目录。无需管理员权限或另装 Node/Python。开发目录可通过本地目录方式关联，使用期间需保留该目录。

## 使用

1. 按上面的方式安装插件，启动 DSH。
2. 打开侧栏「旅行记忆」，点击「导入照片」。可以选择多张照片、选择文件夹，或将照片和文件夹拖进页面。文件夹内的子目录会一并扫描。
3. 确认来源后开始导入。可填写整批说明、指定统一日期或从列表选统一地址。统一地址应用到本批新归档的照片，并保留原始 GPS。日期留空时按拍摄日期分组，缺少拍摄日期的进入「日期待补充」。
4. 原图保存后即可查看，AI 描述、标签和地名在后台继续整理。AI 失败项目可在详情中重新整理；地名可在设置页单独重试，不产生模型调用。
5. 在每日档案的搜索框输入城市、年份和要找的内容，例如「杭州 2025 湖边散步」。可用空格、逗号或顿号分隔条件。城市和年份先在本地筛选，AI 根据候选照片的描述和标签挑选结果。地图城市标记也能进入相关档案。
6. 日期、地点、描述和标签只能从桌面手动修改。原始 EXIF、原话与人工修正分开保留。

导入任务由后台逐项保存。一个资料库同一时间运行一个任务，另外可排队等待最多 2000 张照片。当前任务可以包含更大的文件夹。同一次提交的重试会沿用原任务。重新选择相同文件夹可以再次去重和补回缺失原图。队列容量不足时可以保留选择，稍后重新提交。

归档进度、重复跳过和失败分别计数。每批结束后，在「导入照片」页的结果表核对总数、已保存、重复、已删除、失败和取消。暂停会等待当前照片保存完成，取消会保留已经归档的照片。关机或重开 DSH 后，仍可读取原来源的任务会从保存的进度恢复。浏览器续传时，重新选择同一批文件后会先核对已接收照片的内容。旧任务若缺少校验记录，可以重新导入原照片。失败照片可以从结果表重试。原图保存和 AI 整理分开显示。

完整文件的 SHA-256 用于同一资料库的去重。改名和改目录的相同原图仍会识别为重复；如果活跃档案的原图缺失，重导字节一致的文件可将它补回原档案，不改动说明和编辑记录。曾删除的照片可重新选择原文件并提交导入。AI 使用长边最多 1024 像素的预览。

同一天再次导入会追加到该日记录；相同图片文件可以复用存档和识别结果。首页卡片横向并排，城市名在同一行显示，放不下时省略，详情内按城市展示照片。没有城市的照片单独显示为「地点待补充」。跨日上传的原话标为「这批照片的说明」，保留批次关联，不强行认定每句话都发生在每一天。暂不自动组合多天为一趟旅行。

首页先显示 24 天或 24 个分类，向下滚动接近底部时继续加载，也可点击「加载更多」。某一天照片较多时，详情同样每次展开 24 张。后台状态刷新保留已加载内容和滚动位置，筛选结果同样可以按四种方式浏览。

每日档案可按省份、月份、日期或随机浏览。省份下可进入城市及当天照片，月份按年分组，只显示收录过照片的月份。日期视图右侧的月份条可直接跳转。省、市、月的分类卡片可右键更换封面。方向按钮在最近优先和最早优先之间切换，分类信息缺失的记录随方向移到末尾或开头。

列表使用长边最多 480 像素的封面，详情使用最多 1600 像素的预览。下载原图前会核对文件校验值，发现内容被改动时会给出提示。预览首次按需生成，之后直接复用资料文件夹中的缓存；同图请求合并，最多同时生成两张预览。预览不调用 AI。

右键每日档案卡片，可在原位置修改当天标题、从当天照片中更换封面，或确认后删除整天。省、市和月份卡片也可右键更换封面。右键详情中的照片，可在原位置修改照片说明与标签，或确认后删除该张；删除最后一张会一并移除当天卡片。删除后列表、检索和足迹统计随之更新，操作不调用模型。

删除采用可恢复保存：整日留存删除标记，单图留存删除前快照，原图文件暂不物理清理，因此不会立即释放磁盘空间。当前没有回收站界面；需要恢复时请保留完整资料文件夹。

单张照片显示城市和区县，缺少区县时显示已有地名；每日卡片和照片分组仍以市为单位。拍摄时间、坐标、尺寸与文件校验收在「详细信息」中，编辑状态下也可修正时间与地点，「下载原图」保留。

## 模型和用量

旅行记忆使用 DSH 账号提供的 DeepSeek V4.1 Flash，整理时关闭思考。模型不可用时保留原图，并显示分析失败原因。

每张新图通常分析一次；完全相同图片复用视觉分析。当日摘要使用文字。仅按城市和年份查找时使用本地索引；查询画面内容时只把少量候选的描述和标签交给模型。模型不可用时按本地标签查找。设置页显示服务实际返回的 Token 用量。

图片分析和每日摘要分别设有 600、900 tokens 的输出上限。截断结果会显示失败。设置页的「重置计量」会从零开始统计当前资料库的新用量，已有分析和档案内的历史用量会保留。

照片预览和说明会发给 DSH 账号提供的模型。

## 地点和地图

地图显示与经纬度解析全部在本机完成，数据随插件提供：不加载在线瓦片，不访问在线地名服务，不需要代理、地图账号或 API Key。AI 看图和文字整理仍使用 DSH 里已配置的模型，与离线地图是独立功能。

默认按市整片点亮，可在足迹页切换到区县参考视图；滚轮以鼠标位置为中心缩放，拖拽平移，点击已到访城市可查对应档案。城市面、边界和照片位置更新不调用模型。

城市名称和圆点定位在城市最大主体内部较居中的位置，与省名使用同一种区域内定位方式，不使用首张照片坐标；多岛、凹形或带洞区域避免把标注放在海上或区域外。位置会缓存，新增照片不会让市名漂移。找不到唯一对应边界的城市保留在下方档案卡片中，不用照片坐标冒充城市中心。

显示细节随缩放和点亮模式展开：全国视角只显示省名、省界，去过的省份名称突出显示；放大到全国视角的 2 倍后显示城市名称和市界。按市点亮时，无论放多大都保持市名、市界，悬停也高亮整市；只有按区县点亮且达到 5 倍时，才绘制县界与已到访区县名称。名称互相避让，不堆叠显示。点击省份会放大该省，不会直接跳到任意一个城市；市/区县标记仍可打开所属城市的档案。缩放不会改变已记录的地点或点亮范围。数据仍随插件一次性载入内存，县界按需参与绘制，不需要额外下载。

展示地图是旅行足迹示意图：小块内陆飞地与封闭小洞合并显示，让色块更完整；照片记录中的地点和城市统计保持不变。它不用于判断准确行政边界。

示意处理统一在县级共享拓扑上完成，再合并生成市、省轮廓；保留每个地区的主体和海岛。填色、描边、悬停使用同一份展示几何，相邻地区共用的线只描一次。参考源为 geoBoundaries 2017 年县界，台湾没有该源的县级数据，使用 OCHA 独立轮廓。浏览器不逐面简化，缩放只控制可见层级。

坐标解析仍使用独立的 OCHA/HDX 省市数据及已核对的历史县界，保存原数据来源，展示地图更新不重写历史地点。这些是旅行归档的参考范围，不是最新法定区划或精密测绘数据。定位资料见 data/geo/meta.json，展示地图来源、构建方法和审计见 data/geo/display-provenance.json。

GPS 和原 EXIF 保持不变。未收录的坐标显示「地图未收录该地区，请手动填写」，缺少 GPS 不猜位置。自动结果保存来源、数据版本及边界 ID；更新离线数据后，可独立补查地点，原自动结果留在 placeRevisions，手工填写的地点优先保留。

设置页提供地名处理状态和重试入口。对缺少 GPS 且未填地点的照片，可多选后从离线列表批量指定省市。原照片坐标和 EXIF 会保留。

地图署名与数据许可随插件提供。OCHA/HDX 省市数据采用 CC BY 3.0 IGO；geoBoundaries 区县数据采用 ODbL 1.0，保留 © OpenStreetMap contributors。构建脚本在 tools/，构建时获取来源数据，日常使用不需要下载。

## 插件安装位置

通过 GitHub 命令或 DSH 插件管理器安装的插件由 profile 包管理器保存在 DSH_HOME（默认用户目录下 .dsh）的 profiles/desktop 内，通过 DSH 插件管理页更新或移除。

ZIP 安装器创建的正式副本位于 DSH_HOME 的 managed-plugins/dsh-travel-journal 下，按版本及内容标识分目录保存。更新时建立新副本，再切换旅行记忆的注册路径；不覆盖旧版运行文件，不更改其他插件或模型配置。安装副本与照片资料文件夹独立，删除下载/解压目录不影响已安装插件。

ZIP 安装器使用 DSH 自带的运行时、兼容性检查和配置格式，只替换本插件的目录链接及注册条目；已有锁文件只更新本插件条目，缺失的锁文件保持缺失。不调用包管理器，不重新解析或安装其他插件依赖，安装子进程限制联网。若 DSH 尚未首次启动，请先打开一次后退出再安装；若离线安装失败，会保留错误日志并报告失败，不自动改为联网安装。

## 保存与迁移

在「设置与存储 → 选择资料文件夹」中点击「浏览文件夹」。在系统对话框里确认后立即切换。已有资料库直接打开，空文件夹建立新库。

首次默认目录为用户 .dsh/plugins-data/travel-journal；若 DSH 设置了 DSH_HOME，则使用其 plugins-data/travel-journal 子目录。原图、记录和分析缓存都在所选资料文件夹中，内部使用相对路径。

- originals：按拍摄日分目录，未知日期归入 `unknown`。文件名包含时间、原名和短指纹，完整 SHA-256 保存在照片记录中。
- records：有版本的 JSON 档案，含原话、消息与照片关联、EXIF、AI 分析、人工修正及修订历史。
- state.json：导入草稿、后台恢复状态和实际用量。
- import-queue.sqlite：带版本号的导入任务、文件清单、队列顺序和进度，与本资料库身份绑定。
- analysis-cache.json：可以重建的视觉分析缓存。旧版本遗留的在线地名缓存不再读取，也不主动删除。
- previews：按需生成的封面和清晰预览缓存，随资料文件夹一起移动。停用插件后可删除此目录释放空间，再次浏览会重建，不影响原图或 AI 分析。
- abandoned：主动取消的草稿等保留资料。
- trash：单张照片删除前的整日快照。整日删除标记与完整内容保留在 records 内，由当前插件排除展示和检索。
- .travel-journal-library.json：资料库格式和身份标识，移动时一起保留。

换硬盘或换电脑时，先关闭旅行记忆插件，再移动或复制**整个资料文件夹**。重新启用插件后选择新路径即可，已完成的 AI 分析和人工修改随库保留。需要压缩时可自行打包；插件已移除 ZIP 备份导出/恢复，照片导入仍保留。

已配置路径丢失、硬盘未连接或文件夹身份不符时，页面会提示并暂停库操作。重新连接硬盘后，在浏览对话框里选择原目录或移动后的资料文件夹。可选择已有资料库或空文件夹。

当前路径和整理开关保存在默认目录旁的 travel-journal.local 本机控制目录。新电脑可以在插件里重新选择资料库，并使用自己的 DSH 账号。

请定期将备份保存到另一块磁盘。源照片删除不影响已经成功导入的原图。

## 测试照片

demo 目录包含 5 张公开许可照片和 3 天模拟说明，来源与许可见其中 README。日期、GPS 都是人为写入的测试数据，不代表真实旅行；其中一张故意没有 GPS。导入验证时应标记为演示数据。

开发检查：Node.js 22.13 或更新版本，运行 npm ci、npm run check。
